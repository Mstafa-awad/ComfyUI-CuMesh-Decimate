# Changelog

## 1.0.0 - 2026-08-29

- Initial standalone native `MESH -> MESH` CuMesh decimation node.
- Geometry-only output with optional fresh smooth normals.
- Arbitrary target-face control and all three public CuMesh simplification weights.
- Automatic ComfyUI model unloading and CUDA-cache cleanup.
- Installer reuses a matching CuMesh backend without replacing PyTorch.
